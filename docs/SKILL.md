# Panasonic Let's Note CF-SV8 桌面操作与快捷键技能手册 (SKILL)

本文档汇总了 Panasonic Let's Note CF-SV8 运行 NixOS + DWM 平铺桌面环境下的全部核心快捷键、松下独占圆盘触控板手势以及日常高效操作技能。

---

## 一、 DWM 极简平铺窗口管理器快捷键

> [!NOTE]
> 系统的修饰主键（`MODKEY`）已统一配置为键盘上的 **`Super` 键**（即带有 Windows 徽标的徽标键）。

### 1. 核心应用呼出与会话控制
| 快捷键 | 功能操作 | 说明 |
| :--- | :--- | :--- |
| `Super + Shift + Return` | 启动极速终端 | 打开 Alacritty 终端（无边框，已配置 12px 舒适边距与 Catppuccin 主题） |
| `Super + p` | 打开应用启动器 | 呼出顶部 `dmenu` 启动条，输入应用名首字母按回车启动 |
| `Super + s` | 竞速计时器 / 番茄钟菜单 | 呼出 `dmenu` 选单：开启正向 Speedrun 跑表、25分钟番茄钟或输入自定义倒计时时长 |
| `Super + Shift + s` | 计时器暂停 / 继续 | 盲打一键暂停或继续当前 Speedrun 跑表与倒计时，状态栏实时更新为 `[󰏤]` / `[󱎫]` |
| `Super + Shift + l` | 极简安全锁屏 | 调用 `slock` 立即黑屏锁定系统；盲打当前用户登录密码按回车解锁 |
| `Super + Shift + c` | 关闭当前窗口 | 安全销毁当前获得焦点的窗口客户端（Kill Client） |
| `Super + b` | 显示 / 隐藏状态栏 | 切换顶部 `slstatus` 状态栏的可见性，进入沉浸式全屏视图 |
| `Super + Shift + q` | 退出 DWM 桌面 | 结束 X11 会话并安全退出至 TTY 终端 |

### 2. 窗口平铺布局切换
| 快捷键 | 布局模式 | 说明 |
| :--- | :--- | :--- |
| `Super + t` | 平铺模式 (`[]=`) | **默认主从平铺**：左侧为 Master 主屏区，右侧为 Stack 从属区 |
| `Super + f` | 浮动模式 (`><>`) | 自由浮动窗口，允许窗口重叠与自由移动（类似传统桌面） |
| `Super + m` | 单窗模式 (`[M]`) | 单窗口最大化展示（Monocle），所有其他窗口隐于底层 |
| `Super + Space` | 循环切换上一布局 | 在当前布局与上一次使用的布局之间快速往返切换 |
| `Super + Shift + Space` | 切换窗口浮动状态 | 将当前活动窗口单独在“平铺”与“自由浮动”之间切换 |

### 3. 窗口焦点流转与主从屏调度 (Master / Stack)
| 快捷键 | 功能操作 | 说明 |
| :--- | :--- | :--- |
| `Super + j` | 焦点向下移动 | 顺时针流转选中同工作区内的下一个窗口 |
| `Super + k` | 焦点向上移动 | 逆时针流转选中同工作区内的上一个窗口 |
| `Super + Return` | 提升至主屏 (Zoom) | 将当前焦点窗口对调至左侧 Master 主屏区；若已在主屏则与第一从屏对调 |
| `Super + h` | 缩小主屏区域宽度 | 主屏占比每次缩减 5%（`mfact -0.05`），为右侧从属区域留出空间 |
| `Super + l` | 增大主屏区域宽度 | 主屏占比每次增大 5%（`mfact +0.05`），放大主干工作视野 |
| `Super + i` | 增加主屏窗口容量 | 增加 Master 主屏内允许容纳的窗口数量 (`incnmaster +1`) |
| `Super + d` | 减少主屏窗口容量 | 减少 Master 主屏内允许容纳的窗口数量 (`incnmaster -1`) |

### 4. 虚拟工作区 (Tags 1~6) 调度
| 快捷键 | 功能操作 | 说明 |
| :--- | :--- | :--- |
| `Super + 1` ~ `Super + 6` | 切换至指定标签 | 快速跳转至第 1 到第 6 虚拟工作区 |
| `Super + Shift + 1` ~ `6` | 移动窗口至指定标签 | 将当前选中的活动窗口发送并绑定至第 1 到第 6 工作区 |
| `Super + 0` | 查看全部工作区 | 聚合全标签视图，同时展示所有工作区内的所有窗口 |
| `Super + Shift + 0` | 窗口贴合至所有标签 | 将当前活动窗口设为跨标签全局驻留（在任何工作区均可见） |
| `Super + Tab` | 往返历史标签 | 快速返回上一次浏览的虚拟工作区 |

### 5. 鼠标与窗口交互手势
| 鼠标操作 | 适用区域 | 动作效果 |
| :--- | :--- | :--- |
| `Super + 鼠标左键拖动` | 任意窗口内部 | 瞬间将窗口转为浮动并按鼠标轨迹任意拖拽位置 |
| `Super + 鼠标右键拖动` | 任意窗口内部 | 自由拉伸调整浮动窗口的物理宽高尺寸 |
| `Super + 鼠标中键点击` | 任意窗口内部 | 快速切换该窗口的浮动 / 平铺约束 |
| `鼠标左键点击` | 顶部工作区数字 (1~6) | 瞬时切换至该工作区 |
| `鼠标中键点击` | 顶部窗口标题区 | 将当前标题对应的窗口一键提升至 Master 主屏 |
| `鼠标中键点击` | 顶部右侧状态文本区 | 一键呼出新的 Alacritty 终端 |

## 二、 松下硬件专属 Fn 热键与多媒体控制

松下 Let's Note CF-SV8 的机身 Fn 热键通过标准 AT PS/2 键盘控制器直出标准 XF86 键码，系统已完成原生无缝对接：

| 硬件物理按键 | 对应 XF86 符号 | 联动后端 | 功能说明 |
| :--- | :--- | :--- | :--- |
| `Fn + F1` | `XF86MonBrightnessDown` | `brightnessctl` | 屏幕背光平滑降低 5% |
| `Fn + F2` | `XF86MonBrightnessUp` | `brightnessctl` | 屏幕背光平滑提升 5% |
| `Fn + F4` | `XF86AudioMute` | PipeWire (`wpctl`) | 扬声器 / 耳机一键静音 / 恢复切换 |
| `Fn + F5` | `XF86AudioLowerVolume` | PipeWire (`wpctl`) | 系统主音量平滑降低 5% |
| `Fn + F6` | `XF86AudioRaiseVolume` | PipeWire (`wpctl`) | 系统主音量平滑提高 5%（限制上限 150% 防爆音） |
| 麦克风静音键 | `XF86AudioMicMute` | PipeWire (`wpctl`) | 硬件录音麦克风一键静音切换 |
| `PrtSc` (Fn + PrtSc) | `XK_Print` | `maim` + `Satty` | 交互式框选区域，启动 Satty 极速标注（画框、箭头、文字、马赛克），回车/复制即自动归档保存并写入剪贴板 |
| `Shift + PrtSc` | `Shift + XK_Print` | `maim` + `Satty` | 全屏截图捕获并交由 Satty 进行标注与自动归档保存 |

## 三、 松下经典圆形触摸板手势 (くるくるスクロール)

系统搭载了专为松下 `Synaptics TM3136-020` 调校的专属 Synaptics 旋转驱动，手感顺滑自然：

| 触摸板手势 | 动作与轨迹 | 实际效果与操作技巧 |
| :--- | :--- | :--- |
| **边缘顺时针旋转** | 沿圆形触摸板边缘顺时针画圈 | **平滑向下无极滚动**（长文档浏览旋钮，手腕无需反复抬起） |
| **边缘逆时针旋转** | 沿圆形触摸板边缘逆时针画圈 | **平滑向上无极滚动**（步进灵敏度 `0.2`，微操定位精准） |
| **单指轻触** | 触摸板表面单指点按 | 触发鼠标左键单击（支持轻触拖拽） |
| **双指轻触** | 触摸板表面双指同时点按 | 触发鼠标右键菜单 |
| **三指轻触** | 触摸板表面三指同时点按 | 触发鼠标中键粘贴 / 新标签页打开链接 |
| **双指平移** | 触摸板表面双指同向滑动 | 传统上下平移滚动（与边缘画圈滚动完美共存） |

## 四、 Speedrun 极简计时器与命令行交互 (timer)

顶部状态栏右侧常驻有 `00:00:00` 极简计时器，支持正向竞速跑表、番茄钟倒计时与桌面通知提醒。

### 1. 快捷键与 dmenu 菜单
- 按下 <kbd>Super + s</kbd>：唤起 dmenu 计时选单，可上下选择常用预设或直接键盘输入分钟数（如敲 `10` 回车开启 10 分钟倒计时）。
- 按下 <kbd>Super + Shift + s</kbd>：全局盲打切换暂停与继续。

### 2. 命令行快捷指令 (`timer` / `speedrun-timer`)
可以在 Alacritty 终端随时执行以下指令：
| 命令 | 功能作用 | 说明 |
| :--- | :--- | :--- |
| `timer run` | 启动正向竞速跑表 | 状态栏显示 `[+ 00:00:01]` 开始正向递增跳动 |
| `timer 25m` (或 `timer 25`) | 启动 25 分钟倒计时 | 开启专注番茄钟，状态栏显示 `[- 00:24:59]` 倒数，到期归零显示 `[󰄬 00:00:00]` 并弹窗提醒 |
| `timer 1h30m` | 启动长倒计时 | 支持 `h`、`m`、`s` 自由组合输入 |
| `timer pause` | 暂停计时 | 状态栏图标切换为 `[󰏤]` 锁定时间 |
| `timer resume` | 恢复计时 | 继续计时进程 |
| `timer toggle` | 切换暂停 / 继续 | 适合脚本或快捷键快速触发 |
| `timer stop` (或 `reset`) | 复位计时器 | 归零重置并恢复常驻初始态 `[00:00:00]` |

## 五、 Alacritty 极简终端日常操作技巧

| 快捷键 / 操作 | 功能作用 | 说明 |
| :--- | :--- | :--- |
| `Ctrl + Shift + c` | 复制选中文本至剪贴板 | 显式写入系统剪贴板（CLIPBOARD） |
| `Ctrl + Shift + v` | 从剪贴板粘贴文本 | 粘贴系统剪贴板内容至命令行 |
| `鼠标左键拖拽选词` | 文本即选即拷 | X11 原生直通机制，划选文字即自动暂存至 PRIMARY 选区 |
| `鼠标中键单击` | 极速粘贴选区 | 瞬间将 PRIMARY 选区文本粘贴至光标所在位置 |
| `Shift + PageUp` / `PageDown` | 终端历史回滚浏览 | 快速查看历史命令输出上下文 |
| `Ctrl + Shift + +` / `-` | 动态增大 / 缩小终端字体 | 临时放大查看紧凑代码或日志，按 `Ctrl + 0` 恢复默认 13pt |
